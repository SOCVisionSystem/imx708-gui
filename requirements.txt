# grpcio-tools emits gencode that declares a MINIMUM protobuf runtime
# version. With the bounds left open, a fresh "pip install" pulled
# grpcio-tools 1.14.x (protobuf gencode 7.x) alongside an older protobuf
# runtime and every start-up died with:
#   ImportError: cannot import name 'runtime_version' from 'google.protobuf'
# Keep grpcio, grpcio-tools and protobuf pinned to a single, coherent series.
PySide6>=6.5,<7
grpcio>=1.60,<2
grpcio-tools>=1.60,<2
protobuf>=4.25,<6
